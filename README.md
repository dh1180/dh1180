## 🚀 About Me

- 🌐 **Django · Spring Boot · ASP.NET Core**를 활용해 웹 서비스를 직접 개발하고 운영해 왔습니다.
- 🧩 **REST API · GitHub App/OAuth · JWT · 데이터베이스 모델링 · 웹 크롤링 · 외부 API 연동** 등 서비스의 핵심 기능 구현 경험이 있습니다.
- 🤖 Spring Boot와 **FastAPI 기반 AI 서버를 연동**하고, 오래 걸리는 작업을 `jobId → Callback` 방식의 비동기 구조로 연결한 경험이 있습니다.
- ☁️ **AWS · Docker · GitHub Actions · Railway · Azure · Cloudflare Pages** 등을 활용해 애플리케이션 배포와 CI/CD 흐름을 구성해 왔습니다.
- 🔐 Access Token과 같은 민감 데이터를 **AES-256-GCM으로 암호화해 저장**하는 등 실제 서비스 운영에 필요한 인증·보안 문제를 함께 다뤘습니다.
- 📱 **React · React Native · Expo · TypeScript · Astro · Tailwind CSS**를 활용해 프론트엔드와 모바일 앱도 직접 구현합니다.
- 📈 특히 **K-unirank, HowMuch**처럼 실제 공개 서비스를 만들고 사용자 경험과 데이터 구조를 계속 개선하는 과정에 관심이 많습니다.
- ✍️ 개발 중 부딪힌 문제와 해결 과정은 [기술 블로그](https://dong1936.tistory.com/)에 기록하고 있습니다.
