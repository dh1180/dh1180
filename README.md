- ☁️ AWS · Docker · GitHub Actions · Railway · Azure · Vercel · Cloudflare를 활용해 배포와 CI/CD 흐름을 구성합니다.
- 🔐 OAuth/JWT와 민감정보 암호화 등 실제 서비스 운영에 필요한 인증·보안 문제도 함께 다룹니다.
- ✍️ 개발 과정에서 겪은 문제와 해결 과정은 [기술 블로그](https://dong1936.tistory.com/)에 기록합니다.
